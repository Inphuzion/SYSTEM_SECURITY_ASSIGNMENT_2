This is the sample plaintext for the 2026 RSA assignment. It is deliberately longer than one RSA block of a 2048-bit key, so that a correct implementation must split it into several framed blocks, encrypt each one separately, and concatenate the ciphertext blocks in order. The last block is shorter than the others and is padded with 0xFF bytes. If your tool produces a ciphertext file that is byte for byte identical to sample.enc, your framing, padding, byte order and modular exponentiation are all correct.
